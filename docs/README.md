# Project Documentation

This folder contains the stage-wise documentation required for the capstone.

- `STAGE_DOCUMENTATION.md` – Stage 1 through Stage 6, PRD, testing and progress evidence.
- `PRD.md` – standalone Product Requirements Document.
- `UML_DIAGRAMS.md` – class/data structure, sequence and state-machine diagrams.

The documentation describes the project as actually implemented and does not claim successful kernel-module loading in the current WSL2 environment.
